## About me

I'm a web and full-stack developer with a background in **digital marketing, UX, and project management**. I work across the product journey: understanding the problem, shaping the experience, building the interface, connecting data, testing important flows, and shipping the result.

My portfolio spans a **multi-tenant SaaS product**, a **content and commerce platform**, a **custom WordPress newsroom**, and conversion-focused web experiences.

**My perspective:** good software should serve both the people using it and the business behind it.
