## Sobre mim

Sou desenvolvedor web e full-stack com experiência em **marketing digital, UX e gestão de projetos**. Atuo em toda a jornada do produto: entender o problema, estruturar a experiência, desenvolver a interface, integrar dados, testar fluxos importantes e colocar a solução no ar.

Meu portfólio reúne um **produto SaaS multi-tenant**, uma **plataforma de conteúdo e comércio**, uma **redação WordPress personalizada** e experiências web orientadas à conversão.

**Minha perspectiva:** um bom software precisa servir tanto às pessoas que o utilizam quanto ao negócio por trás dele.

## Tecnologias principais

**Frontend:** HTML · CSS · JavaScript · TypeScript · React · Next.js · Tailwind CSS  
**Backend e dados:** Node.js · PHP · WordPress · PostgreSQL · Supabase · APIs REST  
**Qualidade e publicação:** Git · Docker · Netlify · Render · Playwright · pgTAP

- **Visão de produto:** conectar escolhas técnicas às necessidades das pessoas e aos resultados do negócio.

- **Engenharia full-stack:** trabalhar com autenticação, autorização, APIs, dados relacionais e regras no banco.
- **Entrega responsável:** documentar decisões, proteger ambientes sensíveis, testar fluxos críticos e criar soluções sustentáveis.
