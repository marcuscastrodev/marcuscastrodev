## Sobre mí

Soy desarrollador web con experiencia en **marketing digital, UX y gestión de proyectos**. Me gusta participar en todo el ciclo de un producto: comprender el problema, diseñar la experiencia, desarrollar la interfaz, conectar los datos y publicar la solución.

Mis proyectos incluyen **sitios web responsivos y plataformas WordPress personalizadas**, además de un **prototipo SaaS multiinquilino** desarrollado con Next.js, TypeScript y PostgreSQL.

**Mi enfoque diferencial:** pensar tanto en las personas que utilizan el software como en las necesidades de negocio que debe resolver.

## Cómo abordo el desarrollo

- **Visión de producto:** conectar decisiones técnicas con las necesidades del usuario y los objetivos del negocio.
- **Frontend cuidado:** diseño responsivo, accesibilidad y jerarquía de información.
- **Desarrollo full-stack:** autenticación, autorización, APIs y datos relacionales.
- **Entrega real:** documentar decisiones, probar los flujos importantes, publicar e iterar.
